# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/30a168e3-8158-474f-b9f2-f717d7220314

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Ricerca prodotti online

La ricerca usa le API pubbliche di Wikipedia e Wikimedia Commons: non richiede chiavi, Firebase Functions o un piano a pagamento. I risultati disponibili dipendono dai contenuti aperti presenti; le immagini mostrano l’attribuzione e il collegamento alla relativa fonte.
